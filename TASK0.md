### Why Laravel + Vue?
- Vue.js's ref and reactive APIs provide a native, efficient way to manage appointment lists solely in the client machine's RAM
- Vue's Single File Components (SFCs) strictly enforce the mandatory requirement to separate visual aspects (Templates) from the implementation (Scripts)
- Laravel with Vue (via Inertia.js or Vite) is a community-standard approach
