# Backend Framework Identification


- *In-Memory Data Management:* Ability to manage entities exclusively in the server's RAM without any database persistency.
- *Server-Side Validation:* Ease of strictly validating data and separating endpoints from the implementation.
- *Testing & Coverage:* Availability of native tools to achieve the mandatory maximum code coverage.
- *Learning Curve:* Time required to build the REST API and meet the Week 8 deadline.

### Why Laravel?
- The project already runs on Laravel + Herd, so development can continue immediately with minimal overhead.
- Validation and endpoint structure are strong and already familiar in the current stack.
- Native testing tools and existing project setup support high coverage quickly.
- With the stack bonus applied, Laravel becomes the most practical choice for Week 8 delivery.
